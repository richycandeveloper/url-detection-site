How detection works

  1. Paste a linkEnter any web address. It is validated but never opened.
  2. Indicators are checkedThe URL is split into parts and tested against documented rules.
  3. Review the resultSee the score, the reasons and a recommended action.

Why it matters for telecoms

Telecommunications customers are frequent targets of SMS and web phishing that imitates the network brand, offers fake promos or demands SIM, PIN and OTP "verification". This project studies those patterns using MTN Enugu as the case study.

This is an independent academic prototype. It is not affiliated with, and has no integration with, MTN.

Prototype limits. The detector is rule-based, not a trained AI model. It does not query live threat intelligence or inspect destination sites. Production use needs a backend, an evaluated model and authorized data sources.
